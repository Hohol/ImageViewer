# Image Fullscreen Toggle

Userscript for **Tampermonkey** / **Violentmonkey**: click an image to open it in a dark fullscreen-style overlay (with keyboard shortcuts and optional video fullscreen). Works on **ChatGPT**, **Gemini**, and **Grok**; Gemini and Grok only attach to generated / main-result images, not every `<img>` on the page.

On **Grok Imagine** (post and saved views) the script also adds toolbar controls: delete media, keep or unkeep items, an “unkept only” filter on saved, and a short-lived hide for tiles you just deleted so the grid does not flash them back.

**Install:** add `ImageViewer.js` as a userscript (URLs and `@match` rules are in the file header).
